# Zero Cost POS 🛒

A Point of Sale (POS) app built with React Native & Expo for small businesses.

## 📲 Install the App on Android

Click the link below on your Android phone to download and install the app:

👉 **[Download & Install APK](https://expo.dev/accounts/surajtakkallapelly/projects/zero-cost-pos/builds/58fb5e4b-2945-42ad-8d15-42d68d39a9a5)**

> Open this link directly on your Android device and tap **Download**.

---

## ✨ Features

- 🛒 Product management with camera/gallery image picker
- 🧾 Invoice generation with WhatsApp sharing
- 📊 Sales statistics & reports
- 💳 Payment verification with QR code
- 📅 Daily/monthly sales calendar
- 🔐 Secure login system

---

## 🛠️ Tech Stack

- **Frontend:** React Native (Expo SDK)
- **Backend:** Supabase (PostgreSQL + Edge Functions)
- **Build:** EAS Build (Expo Application Services)
